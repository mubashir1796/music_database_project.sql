# Music Database SQL Project

## Overview

This project focuses on analyzing a music store database using SQL. The database contains information about customers, employees, invoices, tracks, albums, artists, and genres.

The project involves writing SQL queries to explore the data and identify useful patterns related to customers, sales, music preferences, artists, and purchasing behavior.

## Objectives

The main objectives of this project are to:

* Analyze customer and sales data.
* Explore purchasing patterns across different countries and cities.
* Identify popular artists and music genres.
* Compare customer spending and purchasing behavior.
* Practice writing efficient SQL queries for data analysis.

## SQL Concepts Used

The project demonstrates the use of several SQL concepts, including:

* SELECT statements
* Filtering with WHERE
* Sorting with ORDER BY
* GROUP BY and aggregate functions
* DISTINCT
* JOINs
* Subqueries
* Common Table Expressions (CTEs)
* Window functions
* Ranking and partitioning
* COUNT(), SUM(), and AVG()

## Tools

* **PostgreSQL**
* **pgAdmin**

## Database

The project uses the Chinook music store database, which represents a digital media store. It includes data about music, customers, employees, invoices, and purchases.

## Project Outcome

Through this project, SQL is used to transform raw database records into meaningful information about sales, customers, artists, genres, and purchasing trends.

The project demonstrates practical application of SQL for relational database analysis and business-oriented data questions.
